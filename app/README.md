# Нормо-часы

React + TS + Vite + Tailwind + Recharts. Данные: IndexedDB (локально) или Supabase.

- `npm install`, `npm run dev`, `npm test`, `npm run build` (сборка в `../docs`)
- Supabase: выполните `supabase/schema.sql`, задайте `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` при сборке.
- Деплой: GitHub Pages, ветка main, папка `/docs`.
